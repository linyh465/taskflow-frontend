```typescript
// Before: verify(token, JWT_SECRET)
const payload = await verify(token, JWT_SECRET, 'HS256');
```

Fix 2 — Prisma relation connect syntax (scalar vs relation conflict):
```typescript
user: { connect: { id: userId } }
// instead of: { ...body, userId }
```

## 5. Key Discoveries

1. hono/jwt v4 breaking change: verify() needs algorithm as 3rd param
2. Prisma strict TS: cannot mix scalar userId with relation connect in same data object
3. GitHub editor = CodeMirror 6: access via element.cmTile.view (not .CodeMirror or window.monaco)
4. Vercel auto-deploys on every GitHub push to main
